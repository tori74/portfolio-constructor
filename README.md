# Portfolio Constructor

Веб-инструмент для сборки инвестиционного портфеля частного инвестора на Мосбирже под цель и риск-профиль.

Инвестор указывает целевую сумму, срок, ежемесячные пополнения и риск-профиль — сервис собирает рекомендованный портфель из реальных бумаг Мосбиржи с распределением по классам активов.

Используется учениками онлайн-клуба инвестиций «Семья».

## Что умеет

- Принимает на вход: стартовый капитал, ежемесячные пополнения, срок, риск-профиль
- Подтягивает живые данные с Мосбиржи (котировки, лоты, ликвидность)
- Подбирает портфель из реальных бумаг под целевую структуру (по классам активов и риск-профилю)
- Учитывает модельные ориентиры клуба «Семья»
- Выдаёт итоговую структуру с весами, бумагами, ожидаемой доходностью

## Стек

- **Frontend** (этот репо): чистый HTML + CSS + JS, без фреймворков. Inter шрифт. Mobile-first дизайн, валидация форм, обработка ошибок.
- **Backend** (приватный): FastAPI + Python, интеграция с Мосбиржей, движок подбора бумаг под цель.

## Контекст

Реальный коммерческий продукт, используется ежедневно учениками клуба «Семья». Парный проект к [portfolio-analyzer](https://github.com/tori74/portfolio-analyzer): сначала собираешь портфель (constructor), потом мониторишь его (analyzer).

Frontend публичен. Backend остаётся приватным, потому что содержит бизнес-логику подбора.
